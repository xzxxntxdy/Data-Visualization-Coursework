# 姿态 + 模型分析集成方案

## 📊 三张图表概览

### 1️⃣ 关键点识别准确度分析（全宽图表）
- **展示内容**: 17个关键点的平均置信度 + 标准差
- **关键发现**: 
  - 肩部最准确（0.858）
  - 脚踝最困难（0.519）
  - 标准差显示稳定性
- **解读**: 模型学到了上半身优先的特征（COCO数据特点）

### 2️⃣ 身体部位难度对比（左图）
- **展示内容**: 4个身体部位的平均置信度
  - 头部 (59.9%) - 五官识别困难
  - 上肢 (77.5%) - Transformer的专长
  - 躯干 (76.4%) - 相对稳定
  - 下肢 (57.3%) - 最困难的部分
- **解读**: 模型对上半身理解更深

### 3️⃣ 左右对称性与COCO特征（右图）
- **展示内容**: 8对左右部位的置信度差异
- **关键发现**: 
  - 模型对右侧部位识别更准（平均差异0.89%）
  - 反映COCO中大多数人物左侧朝向
- **解读**: Transformer模型完整学到了数据集的统计特性

## 💡 核心解释（模型如何学到人的特征）

### 从Attention到Confidence的联动
1. **Attention热力图部分**（前面）
   - 展示模型focus的部位
   - 说明模型认为重要的特征

2. **置信度分析部分**（当前）
   - 展示模型最终决策的可靠性
   - 说明模型学到的模式深度

3. **联动理解**
   - 高注意力 + 高置信度 = 模型充分学到的特征
   - 高注意力 + 低置信度 = 特征虽然重要但数据有噪声
   - COCO数据集的偏差被完整保留在模型中

### COCO数据集对模型的影响
| 数据特点 | 对模型的影响 | 在分析中的体现 |
|---------|-----------|-------------|
| 上半身清晰 | 优先学上肢特征 | 肩部置信度最高 |
| 下肢常裁剪 | 下肢学习不充分 | 脚踝置信度最低 |
| 左侧呈现 | 左右不对称学习 | 右侧识别更准 |
| 五官图像小 | 脸部识别困难 | 眼睛置信度较低 |
