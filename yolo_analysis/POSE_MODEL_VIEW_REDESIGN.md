# 📊 姿态 + 模型分析页面重构说明

## 🎯 项目目标
将之前使用synthetic数据的Transformer可解释性分析页面，替换为基于**真实YOLOv8推理数据**的综合分析可视化。

---

## 📝 更改内容

### 1️⃣ 新增 D3 图表 (5个)

#### (1) 身体部位难度排序图
- **类型**: 水平条形图
- **数据**: 4个身体部位 (躯干, 上肢, 头部, 下肢)
- **指标**: 平均置信度 + 标准差
- **交互**: 鼠标悬停显示详细数值
- **颜色系统**: 绿(容易) → 黄(中等) → 红(困难)

#### (2) 17关键点排序图
- **类型**: 水平条形图 (17个关键点)
- **排序**: 从最容易到最难
- **颜色**: 按身体部位分组 (红橙绿蓝)
- **标签**: 直接显示置信度百分比
- **覆盖**: 所有COCO 17个关键点

#### (3) 最难关键点对比图
- **数据**: 最难检测的5个关键点
- **排序**: 右踝(51.91%) → 左眼(61.39%)
- **含义**: 这些点需要特殊处理或更高的模型精度
- **配色**: 红色 (danger)

#### (4) 最容易关键点对比图
- **数据**: 最容易检测的5个关键点
- **排序**: 右肩(85.78%) → 右肘(75.61%)
- **含义**: 这些点可靠度高，可直接使用
- **配色**: 绿色 (success)

#### (5) 统计指标面板
- **样本数**: 175张COCO val2017图像
- **总关键点**: 17 × 175 = 2,975个
- **上下肢差**: 23.5% (COCO偏差证据)
- **左右对称**: < 2.1% (完美对称学习)

## 💡 核心发现展示

页面重点展示的4个发现:

### 🎯 发现1: COCO数据集偏差
```
上半身置信度: 80.7% (躯干)
下半身置信度: 57.3% (下肢)
差异: 23.5%

→ 原因: COCO中下肢常被遮挡或截断
→ 影响: 模型学到了这一特点，成为内在特性
```

### ✓ 发现2: 完美的对称特征
```
左右肢体差异 < 2.1%
最大差异: 肘部 (2.03%)
最小差异: 眼睛 (0.38%)

→ 说明: 模型学到了身体对称性
→ 好处: 可用于数据验证和后处理
```

### ⚠️ 发现3: 头部细节精度低
```
眼睛置信度: 61.39%
耳朵置信度: 52-54%

→ 原因: 易受角度、遮挡、光照影响
→ 建议: 这些点需要特殊处理
```

### 💼 发现4: 应用阈值建议
```
高精度 (医学): 躯干关键点 0.7+
全身应用 (运动): 分层阈值 (躯干0.7, 头0.6, 肢体0.5)
实时应用 (游戏): 最大覆盖 0.45+
```

## 🚀 技术实现细节

### D3图表特性
- **响应式设计**: SVG宽度100%，自适应容器
- **交互性**: 悬停显示提示信息
- **可读性**: 清晰的轴标签和图例
- **性能**: 使用D3 selection和join()优化渲染

### 颜色编码
```
#EF4444 (红)   - 躯干 / 危险 / 困难
#F59E0B (橙)   - 头部 / 警告 / 中等
#10B981 (绿)   - 上肢 / 成功 / 容易
#3B82F6 (蓝)   - 下肢 / 信息 / 困难
```

### 字体和大小
```
标题 (h2): 24px, 700 weight
副标题 (h3): 15px, 600 weight
标题 (h4): 14px, 600 weight
普通文本: 13px, normal weight

```
