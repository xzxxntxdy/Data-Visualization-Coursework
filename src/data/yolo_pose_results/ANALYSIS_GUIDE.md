### 🏆 身体部位难度排序

```
1️⃣ 躯干 (Torso)        → 80.74% ⭐⭐⭐⭐⭐
2️⃣ 上肢 (Upper Limbs)  → 73.66% ⭐⭐⭐⭐
3️⃣ 头部 (Head)         → 59.93% ⭐⭐⭐
4️⃣ 下肢 (Lower Limbs)  → 57.26% ⭐⭐
```

**解释**: 
- **躯干最强**: 肩膀和臀部是身体最稳定的部分，易于被正确标注
- **头部次之**: 面部器官用于身体对齐，但在侧角容易出错
- **上肢较弱**: 胳膊运动范围大，遮挡情况多
- **下肢最弱**: COCO中常被截断或遮挡（图像边界、衣物等）

## 🔍 深层洞察

### 1. **COCO数据集偏差的证据**

模型学到的置信度分布**完全反映**COCO标注特点：
- ✅ **上半身更易标注** (通常完整显示)
- ❌ **下半身常被截断** (图像边界问题) 或 **被遮挡** (椅子、桌子等)
- 这导致模型在下肢上的学习不足

### 2. **左右对称性几乎完美**

所有成对关键点的置信度差异 < 2.1%：
```
眼睛  : Δ = 0.38% (完美对称)
耳朵  : Δ = 0.95% (完美对称)
肩膀  : Δ = 1.30% (完美对称)
肘关节: Δ = 2.03% (基本对称)
腕关节: Δ = 1.38% (完美对称)
臀部  : Δ = 0.72% (完美对称)
膝关节: Δ = 0.19% (完美对称)
踝关节: Δ = 0.17% (完美对称)
```

**含义**: 模型学到了**完全的身体对称特征** ✓

### 3. **置信度分布的含义**

```
低置信度 (< 0.5)  → 模型不确定，易出错
中置信度 (0.5-0.7) → 模型中等确定，需要谨慎
高置信度 (> 0.7)   → 模型确定，可放心使用
```

当前数据的特点：
- 48.6% 的关键点置信度 > 0.7 (可信)
- 28.4% 的关键点置信度 0.5-0.7 (边界)
- 23.0% 的关键点置信度 < 0.5 (不可信)

## 📌 关键结论

### ✅ 优势
1. **学习到了身体对称性** - 左右肢体检测一致
2. **躯干识别优异** - 适合上半身应用
3. **分布稳定** - 置信度分布相对均匀

### ⚠️ 劣势
1. **下肢识别较弱** - COCO数据集偏差
2. **头部细节差** - 面部器官(眼睛、耳朵)精度低
3. **极端情况稀少** - 如极端角度、小尺度人物

### 💡 改进方向
1. **数据增强**: 收集更多下肢标注
2. **模型微调**: 对下肢应用特定的权重调整
3. **多模型融合**: 针对下肢使用专用模型
4. **后处理**: 基于对称性约束优化预测
